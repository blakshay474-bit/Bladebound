# Bladebound ⚔️

> **Bladebound: Medieval Battle Arena Web Experience**  
> An immersive, dark medieval fantasy battle arena platform featuring interactive warrior rosters, armoury customization, real-time battle zones, dynamic game modes, leaderboards, and combat HUD.

---

## 🛡️ Project Overview

Bladebound is structured as a full-stack web application:
- **`frontend/`**: Interactive, responsive single-page application built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.
- **`backend/`**: REST API built with **Node.js** and **Express** delivering real-time battle arena data, zones, warrior stats, and inventory endpoints.
- **`stitch_bladebound_medieval_battle_arena_website/`**: Design specifications, UI prototypes, and thematic medieval visual assets.

---

## 🚀 Features

- **Warriors Showcase**: Detailed warrior classes, ability breakdowns, stats, and lore.
- **Armoury**: Weaponry and armor equipment system with stats and upgrade paths.
- **Battlefield & Zones**: Dynamic arena locations and regional combat zones.
- **Combat HUD**: Interactive player battle interface and health/energy metrics.
- **Game Modes**: Duels, team skirmishes, siege battles, and survival challenges.
- **Leaderboards**: Competitive ranking ladders and tournament status.
- **Player Profile**: Character customization, unlocked badges, and battle record stats.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 18
- **Tooling**: Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **Routing**: React Router DOM v6

### Backend
- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js
- **Middleware**: CORS, Dotenv

## 📦 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
The API server starts on `http://localhost:5000`.

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
The client application starts on `http://localhost:5173`.
